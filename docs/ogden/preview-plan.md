# 第四轮隔离预览方案（没有公网部署）

## 已实现：本机或可信同网段测试

推荐在操作者自己的电脑上运行现有仓库。本会话云环境的127.0.0.1/私有地址通常不是手机可访问的家庭网络地址；生产网址的2.0仍404，不要在那里输入测试账号。

准备Node.js 24、npm及本开发分支；不需要Render、Neon、付费TTS或新云资源。现有CI只运行浏览器模拟，不提供公网测试网址。

本机执行：

```sh
npm install
npm run ogden:preview
```

电脑浏览器打开http://127.0.0.1:3100。手机测试时，电脑与手机连接同一可信家庭Wi-Fi，查出电脑自己的私网IPv4地址。例如电脑地址为192.168.1.23：

macOS/Linux：

```sh
OGDEN_PREVIEW_HOST=192.168.1.23 npm run ogden:preview
```

Windows PowerShell：

```powershell
$env:OGDEN_PREVIEW_HOST="192.168.1.23"
npm run ogden:preview
```

手机打开http://192.168.1.23:3100。示例IP必须替换为电脑实际地址。若防火墙提示，只允许家庭/专用网络，不能开放公网。测试结束Ctrl-C；如手动加过本地入站规则，测试后撤销。不要配置路由器端口转发、隧道或公网反向代理。

绑定只接受loopback或显式RFC1918 IPv4，拒绝0.0.0.0、公网IP、域名和production模式。HTTP Host必须匹配选定地址，防止DNS重绑定。该方案用私网HTTP，所以只能输入虚构账号；不承诺传输加密。私网HTTP缺少randomUUID时改用安全getRandomValues生成UUID，不使用Math.random；没有安全熵则明确失败，不伪造保存。

## 测试数据及接口隔离

- runner永远创建内存PGlite，不读取.env或DATABASE_URL，不使用真实账号、订单、密码或支付凭据。重启清空所有测试记录；同一进程中登录、退出、学习和后续复习可验证。
- 专用中文测试登录页自动生成@example.invalid邮箱与测试密码；仅此域名可注册/登录。可以退出和生成另一组测试账号。不要把密码写入公开PR。
- 所有页面标明隔离环境，响应带X-Easy-English-Environment: isolated-preview；使用独立ee_ogden_preview_session Cookie，不与1.0本机会话互相覆盖。
- 支付/订单/管理员/邮件/重置密码接口服务端403，不依赖隐藏按钮。只开放测试认证、2.0API及只读本人1.0进度检查；无实际收款或生产订单。
- MAIL_PROVIDER/MANUAL_PAYMENT_ENABLED/ALLOW_MOCK_CHECKOUT等外部环境变量不会改变runner字面量禁用配置；真实外部数据库地址即使存在也不使用。进程重启测试验证旧测试账号/会话失效。
- 测试输入仅在当前页面，重载或重新认证时清空；只把教材ID、版本、自评、模式、幂等编号写入临时数据库。待确认保存编号在当前标签页按用户隔离，页面刷新仍沿用，不保存自由表达文本。

## 公网备选：尚未实施，必须先批准

目前没有创建服务、项目、数据库分支、域名、隧道或公网预览。若无法同网段测试，须先提出并批准一个独立、受访问口令保护的HTTPS预览环境：明确提供者/工作区/服务名、固定提交、费用上限0、测试人员、自动关闭时间、临时存储和删除办法、环境变量白名单。禁止挂载生产环境组、Neon连接、邮件或支付密钥；内存测试库足够，不需要新Neon资源。当前runner故意拒绝公网配置，不能直接部署冒充已安全开放。

不能直接认定“再建一个Render Free服务”不会影响1.0。Render官方说明免费小时按工作区共享，用尽可能暂停同工作区免费服务，带宽/构建也有计费或暂停边界。因此不能在生产工作区盲目增加预览服务。公网方案需核实独立免费额度与零收费限制，再单独请求创建/公开部署批准。参考：[Render免费限制](https://render.com/docs/free)。
