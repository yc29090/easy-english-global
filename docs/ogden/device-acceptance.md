# 真实手机验收：操作者步骤

当前Android真机、iPhone真机均未执行。模拟测试不能填成真机成功；独立真人教材审核仍0。先按[本地隔离预览方案](preview-plan.md)在自己的电脑/可信Wi-Fi运行，不访问生产2.0网址，不创建云资源。

1. 在电脑运行本分支的npm run ogden:preview；手机与电脑同可信Wi-Fi，用电脑实际私网IP启动并打开对应地址。页面必须显示隔离标志，测试登录自动生成@example.invalid账号。
2. 记录测试用的提交、设备型号、OS及浏览器版本、日期、实际操作者。只用自动生成的虚构凭据；不要填真实邮箱/密码、开真实收款，或把测试密码写入公开报告。
3. Android Chrome与iPhone Safari各使用一份CSV记录。[逐项模板](acceptance/device-results-template.csv)每行都有设备/系统/浏览器/日期/声音名、步骤、预期、实际、结论及问题字段，全部初始NOT_RUN。
4. 按D01-D16实际操作。声音必须实际耳听并记录voice，不与ChatGPT原声等同；正常/慢速差异忽略时如实记录。无法构造无本地语音、离线等条件填UNSUPPORTED和原因，不编造通过。
5. 重点走完学词→操作词→句型→替换→自主表达→改述→保存→复习；断网丢回执后刷新重试，检查同一条练习只记一次。测试页“退出当前测试账号/生成另一组测试账号”用于检查隔离。
6. 只有真实操作者填写实际结果和PASS/FAIL/UNSUPPORTED。反馈失败项、截图或录屏（只含测试数据），不要包含生产账号或密码。自动化脚本不替操作者签署。
7. 测试完Ctrl-C停止预览，撤销手工防火墙临时规则，不做端口转发。重启后测试数据清空是设计行为；若需要跨天测试，保持同一受控进程，或使用提前复习验证，不接生产数据库。

汇总：Android结果待填写；iPhone结果待填写；发音验收待签；发现问题待修复复测。没有合并、部署或生产访问授权。若不能同网测试，先提出独立零费用公网方案并审批，当前没有公网预览地址。
