## 代码/安全发现及修复

| 发现 | 修复与回归 |
|---|---|
| 刷新会丢失待确认请求编号 | 标签页按当前认证用户保留编号和原版本；重试/重新载入仍一次事件，不保存自由输入；存储被阻止时明确只能原页重试 |
| 更新教材后可能把旧页面练习记成新版本 | 新客户端提交实际看到的核心教材版本，服务端验证历史版本；兼容旧客户端；同编号版本冲突409，未知版本404 |
| 已保存后退休教材导致重试无法确认 | 自己已有事件可确认重复请求；任何新的退休/未批准内容练习仍被拒绝 |
| 表达分页使原续学锚点不可见 | 表达/开口续学使用精确task参数，实际链路验证 |
| 私网HTTP缺少randomUUID导致保存失败 | 使用安全getRandomValues生成规范UUID；无安全熵明确失败，不用Math.random |
| 设备语音列表/构造器异常可能抛出 | 安全捕获、清计时、明确降级，不接远程服务 |
| 后退缓存可能显示旧会话页面 | BFCache恢复重新加载认证与进度，不保留旧输入 |
| 网关非JSON或等待过久 | 有界超时、友好错误与重试入口，不显示假保存 |
| SQL状态与payload审核标签不一致 | 展示权威review_status，草稿不冒充批准或计入批准覆盖 |
| 原预览与其他本机会话Cookie重名 | 独立测试Cookie、专用登录、合成邮箱、Host约束及接口封锁 |

认证仍用现有会话摘要/到期/禁用/临时密码规则，会员和99元/试用未改；参数化SQL、CSRF Origin、请求体上限、事务和用户行锁继续保护。前端教材输出转义、没有自由输入上传或语音识别/评分；错误不回显驱动/凭据。生产2.0仍404。
