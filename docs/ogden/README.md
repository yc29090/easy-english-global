# 简单英语2.0：Modern Basic English 独立开发版本

当前教材版本 `mbe-core-101-v3`。在现有项目上新增 `/ogden` 与独立 `ogden_` 数据表，保留1.0及既有learning-v2增强。生产2.0路由仍关闭；没有合并、部署、修改生产数据或创建收费资源。

## 已确认的产品决定

用户确认：付费会员可访问1.0和2.0，无额外收费；99元终身会员价格不变。现有试用身份和到期时间沿用原逻辑；不擅自新增非会员免费范围。开发预览的测试账号可体验全部教材，不代表生产免费政策。

用户授权教材由开发者自查，不再要求用户逐条审核。自查证据明确注明AI开发者身份，不伪造真人教师签名。用户要求全部开发完成后再统一发送真机测试模板；当前未要求用户提前真机验收。

## 当前教材

101核心词、18操作词教学页、11功能句型、8固定组合、27表达任务，共165个教学条目；句型内含33条受控替换表达，不重复算核心词。已完成165条开发者自查及33条替换句检查，独立真人审核0条。

101词中83个对应学术重印历史词表的独立词头，18个明确为现代新增或规则派生形式。另存850项历史参考索引，不能称为现代850词课程已完成。来源、页码、拼写差异和现代适配见[source-audit.md](source-audit.md)。

每词包含中英、分类、历史归属、现代状态与原因、教学顺序、组合、例句、句型引用、表达功能、美式发音策略及审核方法。音标尚未逐词完善，浏览器发音策略不冒称音质已真机验证。教材仅用已编写的完整表达，不随机拼出所谓正确句子。

表达训练有模仿、独立组合、简单释义三个层级，每题至少两种参考；不按字符串判自由答案错误、不调用付费AI。辅助词可能未掌握，界面明确提示。生活/旅行是主线，工作仅发送价格、邮件和询问收货等简单沟通。四条路径共用2.0掌握状态，操作词与其核心词共用主ID，不设闯关或每日限额。核心词支持搜索和分批显示，分批仅减少手机渲染数量。

## 本地试用

```sh
npm install
npm run ogden:validate
npm run ogden:preview
```

访问 `http://127.0.0.1:3100/` 注册/登录本地测试账号，再进入 `/ogden`。仅监听本机，使用临时PGlite，不读取.env或DATABASE_URL；退出后数据消失。生产启动不安装2.0教材。

句型支持选择意思、听读、隐藏英文、自己说和查看参考；改变意思时保持英文隐藏。听力中英文独立显隐。自由输入仅留当前页面，未上传。正常保存回执丢失时重用请求ID；改选状态使用新请求ID；区分保存成功但统计刷新失败。

## 数据与安全

008仅新增来源、原版对照、教材、版本、审核、安装、独立进度和事件共8表；本轮无新DDL。所有学习记录按会话用户隔离，拒绝客户端指定user_id，继承Origin/JSON限制和临时密码/禁用账号检查。

教材同版本不可覆盖；来源/对照同ID不可改写，纠错需新ID。新版本保留旧版本与练习引用。重复导入不清空进度，审核记录也幂等导入，摘要不符则回滚。停用内容保留历史进度，但不再出现在课程/操作词别名/复习中。

## 审核与发布报告

`npm run ogden:review-export`生成[教材自查清单](content-review.md)及完整review-queue.json。reviews.json保留实际自查方法、时间、理由、条目版本和教学摘要。教学内容或版本变化会使旧记录失效。状态批准不能伪装成人类身份或自动给予部署权限。

`npm run ogden:readiness`区分已完成的教材自查、来源核对、会员决定与未完成的真机验收、部署授权。加 `-- --check` 在条件未完成时退出1。报告不修改云端，不开放生产，不代替人工操作者的实际设备测试。

## 发音

仅在点击后用本地localService=true的en-US浏览器语音；正常rate=1，低速请求rate=.65，支持重复与取消。缺少本地美式声音、合成失败时明确降级，不切换远程服务或其他口音。低速请求可能被浏览器忽略，不冒称专门录制的慢速音频。没有麦克风、录音上传或发音准确率。General American是教学目标，真实声音质量仍待最终真机检查。
