# 简单英语2.0：Modern Basic English 独立开发预览

本次首次独立版本以 GitHub `main` 的 `19cc244f2f7f943e4ba4591fc56a9745a9a6a9aa` 为基线。同名远端分支经检查与该主分支完全一致，未覆盖其他独立提交。已有 `learning-v2` 是基于1.0教材的听说联想增强，本项目保留它；新的独立课程统一使用 `/ogden`、`/api/ogden/*`、`ogden_` 表。

**这是第一阶段架构及第二、三阶段部分功能的开发预览，不是完成验收的2.0。** 来源核实和人工教学审核尚未完成，因此不宣称第一阶段教材审核已全部完成。

## 试用

```sh
npm install
npm run ogden:validate
npm run ogden:preview
```

访问 `http://127.0.0.1:3100/` 注册或登录一个本地测试账号，然后进入 `/ogden`。服务仅监听本机，使用嵌入式 PGlite 临时数据库，不读取 `.env` 或 `DATABASE_URL`；停止后数据消失。需要开发依赖。该命令不是生产启动命令，不创建 Neon、Render 或其他云资源。

2.0 API 复用1.0会话、禁用账号和临时密码检查，以及 HTTP 层 Origin/JSON/大小限制。所有用户数据的 user_id 来自会话，禁止客户端指定。当前开发模式允许测试账号预览草稿，**不表示已决定生产免费范围**。生产模式在查询数据库前对所有2.0页面、脚本、样式和 API 返回404。生产启动与原教材导入不会安装2.0教材。

## 本批教材及规范

`data/ogden/curriculum.json`：18核心词（均为18操作词）、18操作词教学条目、11功能句型、8人工可审查的组合草稿、9表达任务（每层3题，每题至少2种参考）。共64条，**人工审核通过0条，正式发布0条**。18操作词教学条目不额外算作18个核心词；目标850词不是当前数量。

每词包含英文、中译、分类、原版归属（三态）、现代化状态、修改理由、教学顺序、组合、例句、句型ID、表达功能、美式发音策略和审核状态。现代化状态是 retained / replaced / added / extension；retained 表示候选保留，不自动确认原版归属。每个已知原版对照有稳定ID、来源、定位与核实状态；原版分类未核实则为 null，不能虚构。

教材只使用显式编写的组合，不随机拼句。表达任务用结构化内容、多种参考与自评；不调用AI、不按字符串判定自由答案正误，也不存储输入的英文。推荐排序检查已掌握的关联核心词和句型，但辅助词可能未学过，界面明确说明这一限制。尚未形成完整核心词闭包或全面分级覆盖。

四条路径共用独立2.0进度。操作词页和对应词条统一为 `ow-*` 主ID，服务端也执行映射，避免多计掌握。18操作词各有独立地址，例如 `/ogden/operators/get`。用户可以自由浏览，未设置每日数量限制或闯关。

## 数据设计与导入

008迁移仅新增：来源、原版对照、教材主表、不可变条目版本、教材审核记录、安装版本哈希、用户进度、练习事件，共8表及复习索引。不修改1.0表、账号、订单、会员或原复习时间。迁移接入现有事务与advisory lock，只在测试数据库执行过，未应用生产。

`installOgden` 在独立事务锁下可重复导入，完全不写用户进度；同manifest版本不同内容或同条目版本不同内容会拒绝并回滚；新版本保留旧版本和练习引用，不删除旧条目。停用条目使用retired状态，不删记录。来源对照保留固定URL/内容哈希；将来需要更正来源时也应采用新的来源ID保存历史。

进度主键 `(user_id,item_id)`；事件主键 `(user_id,request_id)`，包含模式、教材版本、四种自评状态和时间。同一请求重试幂等，冲突返回409。多设备更新按用户行锁串行处理。复习优先未掌握/待复习和到期条目；沿用透明时间间隔算法，但记录独立。没有收费字段或新会员分配策略。

## 发音与隐私

仅在用户点击后使用免费浏览器 Web Speech Synthesis，指定 `en-US` 且只选择 `localService=true` 的本地语音。一次播放固定语音；同设备尽量保持一致，不保证跨设备为同一声音，也不能保证系统声音严格符合General American。没有音标录入或人工发音审核，因此不声称完成了每词音标/发音质量验收。

正常rate=1，低速请求rate=0.65；这是合成语速请求，不是音频降速，也不是专门录制的慢速教材。浏览器可能忽略rate，界面明确提示。支持结束后间隔重复，停止/换页/隐藏页面会取消播放。没有可用本地美式语音或合成出错时提示自行朗读，不偷偷切换远程或英式语音。没有麦克风调用、识别、录音上传、准确率或付费TTS/AI。
