# Android en-US 兼容性修复（PR #12）

最初一轮基于远程 `a04121e`；本次补充基于 `d3558ee`，保留既有提交，只更新 `fix/android-english-speech`。不得合并、部署、执行生产迁移或改变支付开关。本文件替代此前允许其他英语口音的说明。

## 根因与当前实现

- 原生产2.0要求 `en-US && localService===true`，会误拒绝Android浏览器提供的在线美式语音；首次空列表、延迟/缺失 `voiceschanged` 也会导致错误不可用提示。
- PR早期允许其他英语口音的回退不符合本次要求，已删除。最新远程虽已限制2.0，1.0共享播放器、隐私说明、旧测试及PR正文仍保留宽泛回退，必须同步修正。
- 两版只共用 `/speech-policy.js` 的语言/语速规则；2.0使用 `/english-speech.js`，经典版保留独立的直接点击播放生命周期：只选择规范化后为 `en-US` 的voice（大小写及下划线规范化），显式绑定 `voice` 和 `lang='en-US'`。本地优先；缺失来源标记、浏览器在线en-US均允许。GB/AU/CA/NZ、无地区的en及非英语默认声音均禁止。失败只在其他en-US之间尝试，最多3次。
- `/ogden/speech.js`保留原导出契约；`/playback.js`不再实例化现代播放器，保留经典版单词、短句、场景、对话、跟读和听说练习接口、直接speak调用及1500ms/跟读间隔。公共模块独立于2.0发布开关，不妨碍1.0。
- 等待列表最多6秒，200ms有界轮询补充事件；用户点击后就绪则继续本次请求。开始事件最多等待8秒；结束看门狗15～120秒。没有开始事件不显示播放成功，错误消息不输出底层异常中的敏感内容。
- 快速切换有2.0的120ms取消接续窗口（经典版保留原有直接取消/接续）；generation使旧事件失效。停止、离页、后台取消等待、播放与重复，恢复前台不复活旧请求。没有自动解锁朗读、麦克风请求、网站TTS请求或付费服务。
- 正常请求1.0，慢速请求0.55；重复继承所选语速。跟读保留说话间隔。对同声同句的真实开始/结束事件做有限内存时长对比，慢速不足正常时长1.15倍则明确警告并终止重复。这只能提示疑似忽略rate，不能证明音频实际变慢。
- 原先只有URL的音频没有口音审核来源，不能绕过严格en-US策略；适配器暂不播放此类未审核媒体。当前经典教材未提供录音URL。没有删除或修改教材记录。
- 原有教材、认证、会员、订单、迁移和部署输入仍保留历史哈希测试。`public/playback.js`因本次明确授权补充严格en-US策略与可验证状态，从旧逐字节断言中单独移出，新增行为和两版独立生命周期及共同语言规则检查；没有重写其余历史基线。

## 自动化验收范围

实际CI链接、通过/失败/跳过数量记录在PR正文和最终交付报告；不能沿用旧SHA的通过结果。

## 无新增付费资源的预制音频备选研究

Google翻译能发声不代表同一设备的Web Speech API暴露了en-US voice；不能用非官方Google翻译TTS抓取接口绕过，也不接入收费TTS。

当目标设备没有en-US或引擎忽略rate，预制、人工审核的General American音频是可控备选：用有授权的真人录音或经许可离线生成的美式来源，逐条确认教材文本、许可、口音与音质。为正常和慢速分别生成静态文件；慢速可离线用FFmpeg `atempo=0.55`保留音高，浏览器以1倍播放，避免依赖Android TTS rate。录音仍需人听验收，不能由标签或工具处理替代。

本地离线技术实验：2秒440Hz合成测试音，经`atempo=0.55`输出3.618027秒（PCM）；仅验证变速处理能力和大致时长，**不是英语、不是教材资产、不是音质验收**，未提交音频到仓库或上传服务。以后需要正常/慢速文件及哈希、en-US、来源许可、审核人、时长的受控清单，复用现有会员鉴权按教材ID提供音频，不能用裸静态路径泄露付费教材。先测算Git/Render带宽、冷启动和存储，再决定现有免费资源是否可承载，不能保证未来绝对零费用。

本轮没有合格录音资产，未启用预制音频或假造备用端点。若真机仍失败，则需要补充经审核的音频方案，不能宣布问题已在所有安卓设备解决。

## 受控真机验收清单（NOT_RUN）

在后续获授权的测试版本，记录设备、系统/浏览器版本、系统TTS引擎及提示的voice名称/来源；不要发送账号密码或连接字符串。

1. Android Chrome和默认浏览器、iPhone Safari分别听同一句较长教材，确认本地或在线en-US实际出声。
2. 由能判断口音的人确认General American；en-US标签仅为必要程序条件，未审核的声音不得填写音质PASS。
3. 正常→慢速各听同句，慢速必须明显更慢且清晰；记录可闻时长，不能仅凭rate=0.55填PASS。系统不服从参数则FAIL，考虑预制音频。
4. 慢速→重复，确认持续慢速；停止立即静音且不再重复。快速正常/慢速切换不能重叠。
5. 后台、锁屏、离页后再返回，不得突然播放过期请求；必须重新点击。
6. 断网在线语音、无en-US及加载失败应准确提示，不播放其他口音或默认声音。朗读不需要麦克风权限。
7. 覆盖经典单词/短句/场景对话与2.0各学习/练习入口；核实学习进度和账号权限原样保留。

状态分别记录：代码完成、模拟通过、真机出声/口音/慢速验收、正式上线。当前真机未验收，生产未更新；只有自动化通过后才具备进入受控真机测试的条件。


## 紧急补充：同一Android手机1.0可用、2.0不可用

用户提供的历史真机事实：Android Chrome和默认浏览器1.0能播放、2.0不能；iOS 2.0能播放。这是用户报告，不是本候选的真机验收结果。不能笼统归因于Android没有英语引擎。

本轮核查远程main `6c5afeb` 和PR #12 `d3558ee`。当前执行环境的网络策略不包含生产网址；没有绕过限制、登录生产或改变服务。下表是仓库main基线的代码事实，不冒充重新读取生产资产或当前真机声音。

| 调用环节 | main经典1.0 | main现代2.0 | 本候选处理 |
|---|---|---|---|
| 入口 | app.js → createPlayback.play(item) | ogden/app.js → createOgdenSpeech.play(text) | 保留各自入口及独立生命周期，仅共用策略 |
| 初始化 | 静默getVoices；事件刷新缓存 | 捕获synth；getVoices后立即筛选 | 均预加载；2.0兼容在线、来源缺失和延迟列表 |
| 候选筛选 | 任意英语，本地/default优先；无候选还可用默认 | en-US且localService必须为true | 仅en-US，允许本地/在线/未标明来源；禁止其他口音和默认兜底 |
| 首次取消 | 只取消自身持有的旧utterance | 每次play先无条件cancel | 两版空闲首播均不cancel |
| 已就绪播放 | 同一按钮点击内直接speak | 被严格过滤拒绝时根本不调用speak | 已就绪en-US在原点击内直接speak，无定时器延后首播 |
| 列表延迟 | voiceschanged更新，下一次点击再选 | 提示准备好后重新点击；无事件轮询 | 等待有界，事件+轮询，取消后不复活旧请求 |
| 慢速 | 0.55 | 0.65 | 均请求0.55；听感需真机核验 |

可复现的机制：用相同在线en-US或localService缺失的en-US fixture，基线1.0会speak，基线2.0拒绝，新2.0会speak。测试也确认基线2.0有额外空闲cancel。但没有证据证明这部真实Android恰好暴露上述voice，或空闲cancel就是该手机的故障原因，不能把模拟机制写成已证实的设备根因。1.0可响也不证明实际是en-US，因为旧逻辑允许其他英语/默认声音。

风险复核：撤销d3558ee中将1.0整体接入现代引擎的做法，经典版不再依赖现代引擎的120ms取消接续、自动换声重试或其活动会话状态。保留经典直接调用、完成后再重复及跟读停顿。为遵守既有美式要求，经典版仍有必要的en-US校验、加载与错误状态保护，**不是声称与生产字节完全一致**；若该手机1.0原来使用的并非en-US，严格策略可能改变可播放性，必须在真机矩阵核实。不能通过恢复非美式默认声音隐瞒风险。

2.0新增自愿点击“检查本页美式语音”：仅在当前页面显示API可用性、当前en-US名称/本地或在线来源、未采用的语言计数。不显示voiceURI，不保存、不上传、不录音，不触发speak，也不推断系统没有英语引擎。语音列表为空只说明当前尚未取得列表。目的是在后续受控真机测试获取可审阅的过滤证据，不要求安装浏览器或付费服务。

新增tests/speech-difference.test.js使用main历史测试夹具，复现两版差异，检查就绪首播在点击栈内且没有idle cancel，以及延迟加载后stop不会复活请求。测试夹具不向网页提供、不进入生产执行路径。新增经典版手机流程覆盖在线en-US延迟加载、正常/慢速、重复和停止；2.0三项目增加本地诊断无播放/上传测试。

后续四格真机矩阵必须分别填写：Android1.0、Android2.0、iOS1.0、iOS2.0。本候选均NOT_RUN；历史用户反馈单独保留，不能覆盖新候选的待验收状态。验证每格的正常、实际慢速听感、重复、停止、后台恢复、真实语音来源与General American口音。只有对应测试版可用于验收，当前线上仍不是本PR。

初始化补充：经典版继续在发现/播放时读取浏览器的speechSynthesis对象；现代版若初始化时未取得API，会在下一次明确播放点击时重新读取，避免永久锁定首次缺失状态。新增延迟API出现后的两版恢复测试；这也是模拟边界条件，不声称它已被证实为该手机的原因。
