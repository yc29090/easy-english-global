# 用安卓手机安全创建第一个管理员

不需要电脑、Root、付费服务或网页管理员创建接口。管理员创建程序仍是 `npm run admin:create`，保留数据库事务、scrypt 哈希、首个管理员锁及审计。已有普通账号可在本地验证原密码后初始化为唯一管理员，账号 ID 和学习记录保留；网页没有提权接口。

## 第一步：安装官方 Termux

推荐使用官方项目列出的 F-Droid 渠道：

- [Termux 官方安装说明](https://github.com/termux/termux-app#installation)
- [F-Droid 的 Termux 页面](https://f-droid.org/packages/com.termux/)

Android 7 或以上为官方包完整支持范围；Node.js 24 的实际可用性也取决于设备和软件源。不要从广告下载站下载改版 APK。若手机不允许安装官方 Termux，先停止，不要改用公共网页 SQL 编辑器、聊天、GitHub Actions 日志或付费 Shell 输入密码。

## 第二步：准备程序

打开 Termux，下面每行复制进去后按回车。出现 `Y/n` 时输入 `y` 再按回车。

```sh
pkg update
pkg install git nodejs-lts npm
node --version
git clone https://github.com/yc29090/easy-english-global.git
cd easy-english-global
npm install --omit=dev --ignore-scripts
```

`node --version` 应显示 `v24.` 开头。若不是，请先停止管理员初始化。`--omit=dev` 不安装数据库测试引擎等开发依赖，`--ignore-scripts` 不执行依赖安装脚本。项目应放在 Termux 默认的私人目录，不要放到手机共享的下载文件夹。

如果已经在 Termux 下载过项目，不必重新克隆：

```sh
cd ~/easy-english-global
git pull --ff-only
npm install --omit=dev --ignore-scripts
```

## 第三步：在 Neon 找到连接信息

用手机浏览器打开 [Neon 控制台](https://console.neon.tech)，登录你自己的账户：

1. 选择 `easy-english-global`（项目 ID `soft-tooth-72285618`）。
2. 打开 **Connect**，核对分支 `main`、数据库 `neondb`。
3. 使用管理员初始化所需的数据库所有者角色，关闭 Connection pooling，复制 PostgreSQL **连接字符串**。
4. 只复制连接字符串本身，不要复制 `psql` 命令或引号。

连接信息只能从 Neon 页面复制到下一步的隐藏输入框。**不要发送到聊天，不要粘贴在命令后面，不要写进 `.env` 或其他文件。**

## 第四步：创建管理员

回到 Termux 的项目目录，只执行：

```sh
npm run admin:create
```

程序按顺序询问五项信息，**所有输入均隐藏，不显示文字或星号是正常现象**。每项输入完成后按回车：

1. `[1/5]`：粘贴刚才从 Neon 复制的连接字符串。
2. `[2/5]`：输入 `sdqtyc@gmail.com`。
3. `[3/5]`：输入这个账号**目前用于网站登录的原密码**。只有使用新邮箱时才直接回车。
4. `[4/5]`：自己输入一个新的管理员密码，必须与原密码不同。
5. `[5/5]`：再输入一次相同的新密码。

密码需要 16–128 位，至少包含大写字母、小写字母、数字、符号中的三类，不能使用默认密码。推荐用自己的密码管理器生成并保存管理员密码。

不要录屏、截图或使用会记录输入的终端工具。使用可信键盘，不要一次粘贴多项信息。输错可退格；想取消可按 Termux 的 CTRL 再按 C。在五项输入期间取消，或密码不一致、格式错误时，不会进入数据库初始化流程，重新运行同一命令即可。

程序不会读取 `ADMIN_EMAIL`、`ADMIN_PASSWORD` 或 `DATABASE_URL` 环境变量，不加载 `.env`，不接受命令行参数或管道凭据。连接信息与明文密码只用于当前进程内存，不保存文件、日志、环境变量或 GitHub；数据库只存密码的随机盐和 scrypt 哈希。数据库连接强制 TLS 且验证证书。完成后清空手机剪贴板，关闭 Termux 会话。

成功提示：

> 管理员创建成功。连接已通过 TLS 证书验证；请到网站登录，不要再次初始化。

已有管理员时初始化关闭，重复执行不会再创建管理员；原密码错误或账号被禁用时也拒绝提升。已注册邮箱不提供原密码时会被拒绝。成功提升后旧登录会话和旧重置链接失效，请用新密码重新登录。若网络在提交时中断，结果可能未确认；先尝试网站登录，不要删库、重置或反复创建。

## 第五步：验证成功

1. 浏览器打开 [简单英语](https://easy-english-global.onrender.com)。
2. 用 `sdqtyc@gmail.com` 和刚才设置的**新密码**登录。密码只输入网站，不要发给助手。
3. 应看到 **管理后台**，可以创建一个专用试用账号、选择 1–90 天，再检查试用截止日期。
4. 用新建的试用账号登录时先修改临时密码；退出管理员账号后，用普通用户登录不应出现管理后台。

网站为免费实例，长时间未访问后首次打开可能需要等待。不要为了等待时间而切换付费套餐。

完成后只告诉助手“初始化成功”或屏幕上的安全错误类别；不要发送原密码、新密码、连接字符串或含这些信息的截图。助手可以通过只读查询核验管理员数量和权限，不需要接收你的登录密码。

## 验证范围

自动测试覆盖真实 Linux 伪终端的隐藏输入、退格、多行粘贴、密码不一致、Ctrl+C、EOF、SIGTERM、终端恢复、拒绝非交互及旧环境变量入口。数据库集成测试还验证原密码校验、账号禁用检查、原密码不可复用、事务失败回滚、旧会话及重置链接失效、学习记录保留、重复执行只有一个管理员、新密码登录、试用创建、普通用户权限隔离和审计。它们不能替代你手机上的实际执行，本项目未声称已在你的安卓设备创建管理员。

若忘记原登录密码，请停止本地初始化。当前流程不能绕过原密码验证；不要删除已有账号，也不要在 Neon SQL 编辑器手工修改角色或密码。

## 已初始化成功，但网站登录失败

不要重复初始化或发送密码。可运行只验证的本地检查：

```sh
cd ~/easy-english-global
git pull --ff-only
npm install --omit=dev --ignore-scripts
npm run admin:check
```

先从 Neon Connect 复制当前完整直接连接字符串，再运行检查。看到 `[1/3]` 才粘贴一次；`[2/3]` 输入管理员邮箱；`[3/3]` 输入新管理员密码。三个字段全部隐藏，不能通过参数、环境变量、文件或管道提供。

数据库检查强制 TLS 证书验证并使用只读事务。若本地哈希校验不通过，不向网站发送密码。若通过，则只向固定的 HTTPS 生产域名执行一次登录检查，并退出测试会话。检查不创建、提升、重置或禁用账号，不更新密码、会员或学习记录。

只把固定结果码告诉维护人员，不要发送输入值或截图：

- `LOCAL_PASSWORD_MISMATCH`：本次输入与数据库保存的密码不一致，不能据此判断是谁或何时输入错了；不会重置密码。
- `WEBSITE_LOGIN_OK`：本地密码与真实网站管理员登录均验证成功，测试会话已退出；继续检查手机浏览器输入或自动填充。
- `WEBSITE_PASSWORD_REJECTED` / `WEBSITE_ACCOUNT_MISMATCH`：本地验证通过但网站拒绝或返回不同账号，需要维护人员核对部署和数据库配置。
- `WEBSITE_RATE_LIMITED`：网站限制请求次数，应等待后再验证。
- 其他固定结果码：检查未完成或响应异常，不能声称登录成功。

本地检查不能恢复原密码，也不提供绕过身份验证的密码重置入口。
