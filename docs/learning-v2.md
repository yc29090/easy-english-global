# 学习系统 V2

V2 使用现有 500 单词、200 短句、20 场景、100 段对话，不替换教材或普通学习记录。单词—短句使用完整词元和显式词形表；短句—对话分为原句匹配及同场景推荐。同场景推荐不表示原句一定出现在对话中。

第一版关系：717 条单词—短句边、1000 条短句—场景对话边。句型为 4 个固定模板、20 条单独编写的双语变体，其中 4 条免费体验。没有自由拼接或付费 AI 服务。

## 使用

单词／短句卡片有“联想学习”“先听后看”“看中文说英语”入口；导航的“听说联想”也可自由搜索教材、选择句型或主动复习。听力默认隐藏中英文；表达默认中文提示。显示答案、正常／慢速／重复发音、自由跳过均可主动选择，不强制每天学习或打卡。

新结果单独保存到学习练习事件及汇总表，不改变 `progress` 四种状态或原复习时间。未听懂／还不会的独立练习优先推荐，失败 10 分钟后建议复习；成功连续 1～5 次分别建议 1、3、7、14、30 天后复习。任何内容都可提前主动复习。跳过不记为失败。结果是本人自评，不是 AI 能力评分。

## API 与权限

`/api/learning-v2/links?material_id=...` 返回有权访问的双向关联、学习状态和同场景对话。`/patterns` 返回可访问变体。`POST /results` 接收 mode（listening/expression/pattern）、target_id、succeeded、request_id；用户只取自会话，拒绝传入 user_id。同一用户同一 request_id 幂等，冲突结果返回 409。`/review?all=true&mode=...` 支持提前复习，缺省返回到期结果，并提供未掌握内容的关联建议。

所有接口要求登录和已完成临时密码更改，服务端过滤付费教材及到期试用内容。免费用户没有隐藏的收费内容计数或译文泄露。

## 迁移和上线

007 为新增表及索引；不删除或更新用户、原教材、普通学习进度、订单或管理员。迁移由原有事务锁序列化，关系安装另有版本哈希及事务锁。`npm run db:migrate` 后执行 `npm run content:import`，或使用原 Render 启动流程统一准备数据库；相同版本可重复执行，内容冲突会停止而非覆盖。健康检查要求 V2 关系安装完成。

只在隔离 PostgreSQL／PGlite 中执行破坏性测试。此分支未授权合并任何其他 PR，不改变支付开关，也不自动部署生产。真机语音、浏览器兼容性和生产部署状态须另行记录，不能由 CI 结果推断。
