# 两版学习状态视觉优化（仅开发和测试）

内部值仍是learned/mastered/unmastered/review；“待掌握”是unmastered的中文显示调整。1.0的四个自评可手动保存，复习队列仍按next_review_at判断；2.0另包含未掌握/手动待复习及各模式到期规则。本PR没有修改这些算法、时间间隔、状态合并关系或数据库。

共享learning-status.js/css只负责显示：蓝#2563EB、绿#16A34A、橙#EA580C、紫#9333EA作为边框色，使用浅底深字。选中有3px粗边框、勾选、粗体；未选中1px边框。按钮至少48px高，窄屏两列，键盘焦点轮廓和forced-colors选中提示保留。文本/背景对比度至少4.5:1，边框/浅底至少3:1。

点击立即显示待确认选中，并通过aria-busy、aria-disabled和live区域说明保存中；不把尚未收到响应的请求称为已保存。成功后优先重新读取云端记录，失败时尝试重新读取，无法确认则显示上次确认状态并明确提示。2.0在原位更新状态，保留未提交草稿、隐藏文本及替换选择；已有幂等请求编号机制保留。

“已到复习时间”是独立紫色提示，不能替换已保存的“已掌握”等自评，也不改变任何复习队列。两版账号共用、记录分开，2.0各模式记录仍按现有服务器规则维护。

测试覆盖对比度、到期提示不改状态、待确认、实际保存、失败恢复、刷新、重新登录、键盘、模式/版本隔离及Android Chromium和iPhone WebKit布局。手机模拟与ARIA检查不冒充真机或真实屏幕阅读器验收。截图随CI的ui-previews产物提供。

只新增两项静态资源映射；教材、会员、订单、支付、语音及生产数据库不变。创建独立PR，不合并、不部署，不创建收费资源。
