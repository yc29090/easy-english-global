# 简单英语 Easy English

面向英语零基础成年人的中英双语听说学习网站：单词 → 短句 → 场景交流，数量自由，不强制打卡。TypeScript 服务端、PostgreSQL 持久化、原生轻量浏览器界面。Node.js 24 原生运行 TypeScript，无需构建服务。

## 完整新编教材

已提供 **500 个基础单词、200 条实用短句、20 个分级学习场景、100 段双人对话（406 句双语台词）**。每场景 25 个单词、10 条短句、5 段完整对话。涵盖生活 12 场景、旅游 5 场景、简单商务 3 场景；按零基础、日常表达、交流应用三级排序。

这套内容是本项目新编教材，不冒称找回的原版。详细分类、来源与许可见 [教材说明](data/README.md)。旧版 3 个免费补充陪练及其记录完整保留，不计入课程的 100 段。

## 本地运行

需要 Node.js 24+ 和 PostgreSQL 16+（或 Docker）。

```sh
npm install
cp .env.example .env
# 修改 .env 中数据库密码；仅数据库容器使用 POSTGRES_PASSWORD
# 在本地环境设置自己随机生成的 POSTGRES_PASSWORD，DATABASE_URL 使用相同凭证
docker compose up -d
npm run db:migrate
npm run content:validate
npm run content:import
npm start
```

打开 http://localhost:3000 。数据库连接使用 `.env` 中的 `DATABASE_URL`。`docker compose` 只启动 PostgreSQL；应用运行在宿主机。正式环境必须修改开发密码。

首个管理员只允许通过受信任的交互命令行创建，不存在公开初始化接口。先设置数据库连接，再运行下述命令；脚本隐藏输入密码并要求确认（16–128 位，至少三类字符，拒绝默认密码）：

```sh
npm run admin:create
```

脚本不会把已有普通账户提升为管理员，也不会覆盖现有管理员。已有管理员时初始化关闭；不要把 ADMIN_PASSWORD 放入 Render Web Service。自动化仅允许临时环境注入，用后清除。

## 功能

- 默认中文，切换 English，界面偏好保存于当前浏览器。手机和桌面适配。
- 邮箱注册、登录、退出、密码修改、忘记密码、一次性 30 分钟重置链接。注册即为免费用户；邮箱验证不在本版范围。
- 单词/短句/场景列表、双语搜索、场景及学习状态筛选，正常/慢速发音，已学习/未掌握/已掌握/待复习，云端保存记录。
- 配置 HTTPS 音频时优先播放，否则使用设备 Web Speech 的英文语音（慢速 0.65）；设备是否有英文语音及离线可用性由浏览器决定。
- 免费账号只获取 `is_free=true` 教材及课程对话（前两场景 50 单词、20 短句、10 对话）。试用和永久会员可访问完整教材。过期后回到免费权限，保留已有记录。
- 管理后台：创建 1–90 天试用、密码随机生成并仅显示一次、强制更改临时密码、延长 1–90 天试用、禁用/启用、升级永久会员、操作审计。管理员账号受保护。
- 订单固定为 9900 分 CNY（人民币 99 元），待处理订单去重。模拟确认事务化、幂等、校验订单归属。**没有接入真实支付。** 仅非生产环境设置 `ALLOW_MOCK_CHECKOUT=true` 才允许模拟确认升级；生产必须为 false，否则拒绝启动。生产页面隐藏下单/模拟确认按钮，服务端同时拒绝，由管理员授权试用或会员。

## 教材安装与数据保护

`npm run content:import` 默认安装随源码附带的完整新编教材，也可通过参数指定完整 JSON，详见 [导入文档](docs/content.md)。需先运行数据库迁移。

导入事务只新增缺失记录，不删除或覆盖教材、用户学习记录、试用或会员数据；相同版本重复执行为零新增，冲突时全部回滚。稳定 ID 保证现有发音、掌握状态、复习和继续学习位置可以关联同一条教材。已有其他教材不会被清空，因此数据库总数可以大于本套教材数量。

## 免费测试部署

Render 配置已提供在 [render.yaml](render.yaml)，选择 Free Node Web Service。Build：`npm install --omit=dev && npm run content:validate`；Start：`npm run start:render`；健康检查：`/health`。启动前自动进行安全迁移与教材准备，重复冷启动不会重置数据。

生产必需数据库连接和 TLS，站点地址优先 APP_URL，否则使用 Render 的 RENDER_EXTERNAL_URL。邮件推荐 MAIL_PROVIDER=resend、RESEND_API_KEY、MAIL_FROM；也可明确 disabled 做无邮件测试。秘密只填 Render 环境变量，禁止默认管理员密码。详细八步说明、免费数据库选择、一次性管理员初始化和部署后 `npm run smoke -- https://实际域名` 检查见 [部署文档](docs/deployment.md)。

没有使用 Render 授权，未创建真实服务、数据库或邮件账户，不能声称已经上线。

## 安全设计与限制

密码为随机 salt + scrypt；数据库只存会话和重置 token 的 SHA-256，Cookie 为 HttpOnly/SameSite=Lax，生产 Secure。所有修改接口校验 Origin 和 JSON，设置 CSP/防嵌入/防 MIME 嗅探，SQL 参数化，后台权限及教材权限均由服务端校验，不信任前端身份或金额。新密码会撤销所有旧会话，禁用用户立即撤销会话。

数据库共享限流防重启绕过，按服务端所见 IP 限制认证尝试。应用默认不信任 X-Forwarded-For；反向代理下多个用户可能共享限流额度。正式上线需在可信入口增加单账号/入口限流和监控，并定期清理过期 `sessions`、`password_resets`、`rate_limits`。后台用户列表目前显示最近 500 个账号。

密码重置支持 Resend HTTPS API（Render 免费服务推荐）或允许出站 SMTP 的环境。明确设置 MAIL_PROVIDER=disabled 时隐藏找回密码，接口拒绝请求；已启用但发送失败时返回统一信息防邮箱枚举，并记录不含秘密的失败日志。部署后需要实际验证收信。当前版本尚无邮件验证、真实支付、多因素认证、审计查看页面或教材编辑 UI。

## 简单英语学习方法（听说学习版）

为英语零基础成年人设计：**先听、再跟读，从最简单的单词到常用短句，最后练习简单场景交流**。不要求复杂语法，不强制打卡，不设每日学习数量或必须完成的任务；学习路径是建议，任何时候都可以搜索、按场景分类自由学习。

首页突出“继续学习”和“开始复习”。专注训练一次呈现一条内容，用户自由前进或结束；位置与掌握状态跨设备保存。翻译和英文可分别隐藏；正常/慢速发音、重复播放、跟读留白均可一键使用，切换页面或切到后台会停止播放。跟读只提示用户开口，不录音、不自动判断发音正确性。

智能复习是透明的状态规则：未掌握 10 分钟、待复习 1 小时、已学习 1 天、首次已掌握 3 天；连续标记已掌握后延长为 6、12、24、30 天（最多 30 天），再标记未掌握会重置间隔。这个“连续掌握次数”仅用于单条教材排期，不是每日打卡。到期队列优先未掌握，然后待复习、已学习和已掌握；也可以主动复习全部已学内容，不必等到时间。会员到期后保留数据，队列只返回当前有权限访问的教材。

全套教材现有 **100 段课程场景陪练**，另保留 3 个免费补充陪练：第一次见面、买水、工作求助。可选择任一角色，先听对方、再自己说、手动进入下一句，随时重练；角色、当前句子和完成次数云端同步。补充陪练不计入课程的 100 段，也未接入付费 AI。

已有数据库需要执行 `npm run db:migrate`，升级说明见部署文档。新增验证覆盖复习排期、音频重复/停止、迁移不丢数据、复习权限过滤及陪练隔离/恢复；DOM 流程测试验证首页继续、隐藏文字、复习和角色对话，不能替代安卓/iPhone 的实际音频及布局验收。
